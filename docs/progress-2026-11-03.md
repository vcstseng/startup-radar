## 已確認的篩選規則

1. 不必選滿三欄，可以只選一個維度，也可跨產業探索。
2. 同欄多選為任一符合（OR）；不同欄之間必須同時符合（AND）。
3. 每欄可加入的分類依另外兩欄決定，忽略本欄已選條件，保留在同欄增加其他方向的可能；不改成全部欄位只顯示最終交集內的分類。
4. 候選筆數為 0 且未選的分類隱藏；已選條件保留，方便取消。取消或撤回後重新計算並恢復選項。
5. 上方總筆數是所有已選條件的實際結果；選項旁不再顯示容易混淆的候選筆數。

固定說明：「每欄可以多選，符合其中一項即可；不同欄的條件則必須同時符合。不必選滿三欄。」
