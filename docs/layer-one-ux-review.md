# Layer 1 UI／UX Review

範圍：已部署的分類入口；本輪先 review，不改介面、不擴充 Layer 2／3。

網站：<https://vcstseng.github.io/startup-radar/>

部署已成功，GitHub Actions 的 build、八項測試及 deploy 皆通過。公開頁面可讀取 catalog，顯示完整分類入口。

## 優先順序

1. **縮短開始選擇前的距離。** 桌面 1280×800 檢查中，第一個選項約在頁面 y=732；手機 390×844 約 y=869，已在首屏下方。建議縮短介紹、把範例收成輔助說明、減少分類前的重複數量與留白，讓使用者早點看到可勾選項目。
2. **縮小固定操作區。** 尚未選擇時，條件區已約 196px（桌面）／226px（手機），目前選擇、尚未選擇、規則與操作都在同一塊。建議初始只呈現簡單引導及總數；選取後再顯示 chips。手機捲動時固定簡短的筆數／下一步列，完整說明與條件不必全部固定。
3. **減少次要操作干擾。** 撤回、清除與複製連結目前一開始即呈現，前兩者停用。建議有選取後才顯示相關操作，主動作維持查看結果，避免初次使用者先理解所有控制。
4. **刪除重複的分類計數。** 全站 25／22／28、每欄總類數及目前顯示數重複出現。建議每欄保留總類數；有條件造成縮減時，才顯示剩餘可選數。選項旁不重新加回紀錄數。

## 保留

用途標題、三個問題式入口、同欄 OR／跨欄 AND、多選條件 chips、取消與撤回、候選 0 筆隱藏但已選保留、手機維度切換。

查看結果停用是目前只完成 Layer 1 的範圍限制，不是此次發現的程式錯誤。它仍會中斷一般人的完整探索旅程；需待 Layer 2 的設計與實作完成後才可解除。本 review 不藉此擴大範圍。

以上為介面檢視與幾何量測得到的問題及設計判斷，尚未進行一般使用者測試。
